1|Every company moving to SAP's cloud carries hundreds of custom ABAP programs written over fifteen years. Each one must be checked against Clean Core rules before it can move, and today that review is done by hand, by the few people who know both worlds. I asked a narrower question than "can IBM Bob do this review": how well does it do it, measured?
2|So I built the exam before the demo. Four synthetic legacy programs with forty-one planted problems, a twelve-rule catalogue, and an answer key sealed by hash on September twenty-fourth, before Bob saw any code. The organisers confirmed this preparation.
3|In Bob I built a custom mode, Clean Core Architect: a senior SAP architect that audits against the catalogue only, never invents a rule, and never claims something is verified on a system it has not seen. Read and edit tools only.
4|One prompt per program. Bob reads the rules and the sample, then writes a JSON report; every write is approved by hand. Four audits cost zero point six six Bobcoin. Later, three programs were rewritten by three parallel sub-agents in sixteen minutes.
5|This is Bob's output on the vendor ageing report. Problem three: raw database SQL that the cloud version forbids. Problem seven: Bob noticed the comment promises a currency conversion the code never does. And the right column lists what Bob could not verify, instead of guessing.
6|Against the sealed key: twenty-seven of twenty-nine rule problems, on the right lines. But only one of twelve business-logic bugs. Ninety-one percent of the judged findings were right. Bob is a strong first reviewer for rules and a weak one for logic, and now I can say that with numbers.
7|Then Bob rewrote one program: a data view, a class, seven unit tests. On a real SAP trial system the view failed on exactly the two objects Bob had marked candidate. With stand-in tables the class compiled and all seven tests passed, after two syntax fixes that only a compiler finds.
8|This is the honest picture: four programs audited and scored, four rewritten, one tested, none verified on a customer's system. Every dashed cell is a claim we chose not to make. Total cost: about four of forty Bobcoin. The human stays in the loop, and now I know where.
